One funny single-line sport the Olympics rejected: Competitive Fitted-Sheet Folding — athletes race to fold a fitted sheet neatly, and the first to finish is disqualified for lying. Real enough to sound like a broadcast, absurd enough to be funny.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT`) and prints it.
